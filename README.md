# 골리앗 크레인 안전 점검 드론

조선소 도크의 골리앗 크레인을 드론으로 점검하는 시스템임. 골리앗 크레인은 도크 위를 가로지르는 대형 문형 크레인으로, 선박 블록을 들어 옮기는 조선소의 핵심 설비임. 드론에 실린 Jetson Orin Nano가 비행 중에 균열과 부식을 실시간으로 찾아내고, 관제 화면에 점검 우선순위를 띄움.

- 대회: 2026 K-조선 해커톤
- 팀원: 서은수, 정수빈, 정혜민

## 왜 필요한가

- 골리앗 크레인 상부는 점검자가 직접 올라가야 해서 추락 위험이 큼
- 상부 프레임은 주행과 권상으로 동적 하중을 계속 받아 금속 피로 균열이 생김
- 해풍과 염분, 갈매기 배설물의 산성 성분이 강철 프레임, 볼트 체결부, 레일을 부식시킴. 피해는 사람이 보기 가장 어려운 크레인 윗면에 집중됨

(사고 사례와 출처는 계획서 확정본 기준으로 작성 필요)

## 무엇을 하는가

1. 드론이 크레인 상부를 비행하며 영상을 촬영함
2. 기체에 실린 Jetson Orin Nano가 균열과 부식을 픽셀 단위로 분할함
3. 결함 면적 비율로 AI 기반 점검 우선순위 4단계(정상 / 경미 / 주의 / 위험)를 판정함
4. 결과를 관제 대시보드에 실시간으로 표시하고 기록으로 남김
5. 부가 기능으로 조류 둥지를 인식함 (조선소 환경 특화 기능)

## 점검 우선순위 기준

우선순위는 결함 영역이 프레임에서 차지하는 면적 비율로 정함. 결함이 하나라도 잡히면 정상이 될 수 없고, 한 프레임에 결함이 여러 개면 가장 높은 단계가 종합 단계가 됨.

| 단계 | 균열 | 부식 |
|---|---|---|
| 정상 | 결함 없음 | 결함 없음 |
| 경미 | 0.3% 미만 | 3% 미만 |
| 주의 | 0.3% 이상 1.5% 미만 | 3% 이상 12% 미만 |
| 위험 | 1.5% 이상 | 12% 이상 |
